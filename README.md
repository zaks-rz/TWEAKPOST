## ✨ Features

- **⚡ Performance Boost:** Optimize CPU, RAM, and disk usage for maximum gaming and productivity speed.
- **🛡️ Privacy & Security:** Disable telemetry, background tracking, and unnecessary data collection.
- **🎨 System Customization:** Tweak hidden Windows settings, context menus, and visual effects easily.
- **🔄 One-Click Undo:** Safely create backups and restore default settings at any time with a single click.
- **📦 Clean Debloater:** Remove pre-installed bloatware and useless background apps.

---

## 🚀 How to Run

No installation required! Just download and run the executable.

1. Go to the **Releases** section on the right side of this page.
2. Download the latest `ZAKS_TWEAKPOST_PRO.exe`.
3. Right-click the file and select **Run as Administrator** (required to apply system tweaks).
